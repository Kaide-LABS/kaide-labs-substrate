# frameworks/

Operational frameworks. Stage-agnostic decision tools.

## Files

- `sourcing_framework_v1.md` — How to source new prospects in 60-90 min blocks. Re-source every 60 days.
- `vertical_whitelist.md` — Halal vertical whitelist + hard-kill verticals. Apply at sourcing stage, not dossier stage.

## Query when

- Sourcing new prospect candidates → both files
- Hard-kill filter check on a candidate → `vertical_whitelist.md`
- Operational decisions independent of any specific prospect → relevant framework
- Updating sourcing motion based on learned patterns → both files
