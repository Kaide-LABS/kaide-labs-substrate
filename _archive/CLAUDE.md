# Archive — Substrate Navigation

Pre-substrate artifacts preserved for historical reference. Files here are NOT canonical operational references — they are deprecated by current substrate content but retained because deletion is asymmetric (zero cost to keep, non-zero cost to lose).

## Files archived

### `legacy_prompts_pre_template_abstraction.md`

The original 14-step prompt collection used during Tracelight, AS, and Solvo sprints, before abstraction into reusable templates. Each prompt in this file contains prospect-specific content (founder names, verified intel, specific architectural anchors) that has since been parameterized in `pipeline/templates/STEP_*.md`.

**Use the canonical templates for active sprints.** This file exists only to:
- Show what original prompts looked like before abstraction (useful if questioning a template's parameterization)
- Provide worked examples of how to fill specific template placeholders for a specific prospect
- Audit trail of pre-substrate operational discipline

**Do not edit this file.** If a template needs improvement, edit the template directly in `pipeline/templates/`. This file is frozen.

## Archive principles

- File here, don't delete. Keeping a deprecated file has zero substrate cost; deleting it loses recoverable institutional knowledge.
- Add a YAML frontmatter `archived_from: [path]` and `archived_at: [date]` to any file added here.
- Explain why each file is archived (in this CLAUDE.md, not in the file itself).
